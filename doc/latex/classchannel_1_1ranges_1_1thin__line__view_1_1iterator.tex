\doxysubsection{Detailed Description}
An iterator that generates the integral points nearest to the ideal ray. 

The ideal ray is defined by its initial coordinates, the delta vector (magnitude), and the movement vector (direction). Because it is a ray, it does not have a built-\/in terminal point.
