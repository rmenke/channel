Implementation of the Bresenham-\/\+Murphy thick line drawing algorithm in C++20.

This is a header-\/only library. The configuration script is used to set up the test harness and confirm that the necessary compiler features are available.

There are likely more efficient implementations out there, but as the Murphy paper is frustratingly opaque, this implementation serves as a pedagogical example.\hypertarget{md__r_e_a_d_m_e_autotoc_md1}{}\doxysection{\texorpdfstring{Using the library}{Using the library}}\label{md__r_e_a_d_m_e_autotoc_md1}

std::pair p0{123,45};
std::pair p1{-67,89};

// Thin line example

    // do something with the coordinates
}

// Thick line example
for (auto &&stroke : channel::views::line(p0, p1, thickness)) {
    for (auto &&[x, y] : stroke) {
        // do something with the coordinates
    }
