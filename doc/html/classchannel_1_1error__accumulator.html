Detailed Description

The Bresenham error accumulator.

A simple object that maintains the accumulated error from the ideal line. Depending on the value of _error, the update() member function may indicate that motion is needed along the x-axis, the y-axis, or both.

The operation is deceptively simple. When the error accumulator exceeds \(-\frac{\mathop{\mathit{dy}}}{2}\), it emits an instruction to move horizontally. When the error accumulator falls below \(\frac{\mathop{\mathit{dx}}}{2}\), it emits an instruction to move vertically. It then updates the error accumulator according to the move: a vertical move increases the accumulator by \(\mathop{\mathit{dx}}\) and an horizontal move decreases it by \(\mathop{\mathit{dy}}\); both changes may happen but at least one is guaranteed to occur. For the first octant, this means that a vertical move is emitted for roughly \(\frac{\mathop{\mathit{dx}}} {\mathop{\mathit{dy}}}\) horizontal moves.

Note
This is actually Zingl's modification of Bresenham's algorithm. It requires one more comparison per update() call than traditional Bresenham, but it is octant-independent while Bresenham is restricted to the first octant.
